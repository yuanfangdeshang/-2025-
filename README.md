# 星语年册-StarryChat

一个基于 Web 的微信私聊年度报告生成器，支持动画效果和数据可视化。

## 📸 效果预览

- 开场动画：全年聊天记录快速闪回
- 分页报告：6页精美数据展示
- 数字动画：从0滚动到实际数值
- 滚轮翻页：滑动底部后再滑切换页面

## 🚀 使用方法

### 1. 导出聊天记录

使用 [留痕/WeChatMsg](https://github.com/LC044/WeChatMsg) 工具导出聊天记录为 JSON 格式：

1. 下载并安装 WeChatMsg
2. 选择要导出的私聊会话
3. 导出为 JSON 格式

### 2. 生成报告

1. 双击打开 `index.html`
2. 点击选择导出的 JSON 文件
3. 选择你的视角（你是对话中的哪一方）
4. 点击「开始回顾」

### 3. 添加背景音乐（可选）

将音乐文件命名为 `bgm.mp3` 放在 `index.html` 同目录下即可。

## 📊 报告内容

| 页面 | 内容 |
|------|------|
| 01 Overview | 总消息数、双方发送数、会话数、天数 |
| 02 Words | 总字数、双方字数、字数比例 |
| 03 Time | 聊天高峰时段、最活跃星期、疑问句比例 |
| 04 Emoji | 双方最常用的表情 |
| 05 Keywords | 高频词汇 TOP5 |
| 06 Ending | 年度总结 |

## 🎮 操作方式

- **滚轮**：页面内滚动，滚到底再滚一下翻页
- **键盘**：↑↓ / 空格 / 回车 翻页
- **触屏**：上下滑动翻页
- **右侧圆点**：点击跳转指定页

```
wechat-chat-report/

```

## ⚙️ 技术特点

- **纯前端**：无需服务器，本地直接运行
- **单文件**：所有代码集成在一个 HTML 中
- **响应式**：适配手机和电脑
- **隐私安全**：数据完全在本地处理，不上传任何信息

## 📝 JSON 格式要求

支持 WeChatMsg 导出的标准格式：

```json
{
  "session": {
    "nickname": "对方昵称",
    "type": "私聊"
  },
  "messages": [
    {
      "createTime": 1704067200,
      "formattedTime": "2025-01-01 12:00:00",
      "type": "文本消息",
      "content": "消息内容",
      "isSend": 0,
      "senderDisplayName": "发送者名称"
    }
  ]
}
```

## 🎨 自定义

修改 `index.html` 中的 CSS 变量可以自定义颜色：

```css
:root {
  --me: #a78bfa;      /* 我的主题色（紫色） */
  --them: #ff6b4a;    /* TA的主题色（橙色） */
  --bg: #0a0a0f;      /* 背景色 */
}
```
